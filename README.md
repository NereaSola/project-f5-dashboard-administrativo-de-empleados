# project-f5-dashboard-administrativo-de-empleados

## Características:

Desarrollo de un dashboard administrativo, mediante una página de login en el cual se debe introducir email y contraseña correcta. Tras ello se accede a la página de dashboard de empleados en la que se puede ver la foto y datos de los empleados, también hay un buscador por orden alfabético.

### Programas utilizados:

**STITCH**: Para crear las páginas tanto de login como de dashboard, se han realizado los mockaups a través de Stitch.

**HTML5**: Se ha construido la base de la página.

**SASS**: Se han seleccionado los estilos.

**JavaScript**: La lógica del login y del buscador alfabético se ha generado mediante javascript.

**Vitest**: Comprobar que el código funcione óptimamente. 

**JSDOM**: Verificar que la interfaz responda correctamente
